B-POP
======

[github.com/marcasedda/BPOP](https://github.com/marcasedda/BPOP)

Semi-analytical population synthesis code for black hole binaries formed in young, globular and nuclear star clusters, written in C++, with a Python package for merger rates and mock catalogues. I am one of the core developers. My main contribution is the formalism that follows the secondary branches of hierarchical merger trees.

SEVN
======

Rapid single and binary stellar evolution code that follows stars from the zero-age main sequence to the formation of compact remnants. I am a developer, and I implemented in it the remnant masses from my core-collapse supernova models.

POSYDON
======

Binary population synthesis code built on grids of detailed MESA single and binary star models. I have been a user since 2025, after the POSYDON school in Chicago.

HYPERION
======

1D hydrodynamical code for core-collapse supernova explosions and their light curves. I used it to explode the progenitor models in my work on remnant masses.
