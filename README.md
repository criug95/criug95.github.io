# criug95.github.io

Personal website of Cristiano Ugolini, built with the [AcademicPages](https://github.com/academicpages/academicpages.github.io) Jekyll template.

## Where things are

- `_config.yml`: name, sidebar and links
- `_data/navigation.yml`: top menu
- `_pages/`: one Markdown file per page (about, research, papers, software, talks, teaching, cv)
- `images/profile.png`: sidebar photo (replace it with your own)
- `files/`: PDFs, e.g. the CV

## Going online

1. Create an empty public repository called `criug95.github.io` on GitHub.
2. Upload the contents of this folder (not the folder itself).
3. In the repository, go to Settings → Pages and set Source to "GitHub Actions".
4. Every push rebuilds the site at https://criug95.github.io within a couple of minutes.
